# Credit Card Fraud Detection App

This project predicts whether a credit card transaction is fraudulent using Machine Learning.

## Tech Stack
- Python
- Streamlit
- Pandas
- Scikit-learn

## Files
- fraud_detection.py → Streamlit web app
- fraud_detection_pipeline.pkl → Trained ML model

## Run Locally

pip install streamlit pandas scikit-learn joblib
streamlit run fraud_detection.py
